# LimitLens 0.2.3

Première release publique de LimitLens.

## Inclus

- Application macOS de barre de menus.
- Widgets macOS OpenAI, Claude Code et vue combinée.
- Configuration OpenAI seul, Claude seul ou les deux.
- Sandbox macOS avec autorisations de dossiers explicites.
- Import optionnel du jeton OAuth Claude Code pour l'usage exact.
- Interface en français, anglais et espagnol.
- README français, captures de démonstration et audit sécurité public.

## Sécurité

- Aucun serveur LimitLens.
- Aucune télémétrie.
- Secrets stockés dans le trousseau macOS.
- Captures de README générées avec données fictives.
- Audit de publication : `docs/security-audit-2026-05-20.md`.

## Note Gatekeeper

Une archive pleinement notarizée nécessite un certificat Developer ID et un profil `notarytool`. Si la release contient un build non notarizé, macOS peut demander une ouverture manuelle via clic droit puis "Ouvrir".
